## 🎯 Quick Start

### Option 1: Use the Live Application
1. Visit: https://kervinapps.com/LifePlanner
2. Choose your Kevin version (Working or Job Search)
3. Explore your personalized schedule

### Option 2: Run Locally
```bash
# Clone the repository
git clone https://github.com/denizen-star/toronto-guide.git
cd toronto-guide/lifeplanner/v1.0

# Open the web interface
open web/index.html
```

### Option 3: Deploy Your Own
```bash
# Copy the v1.0 folder to your web server
# Serve the web/ directory as your document root
# Access via your domain/index.html
```
